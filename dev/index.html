PerfectForms.jl

PerfectForms enumerates perfect-form orbits using Mathieu Dutour Sikirić's polyhedral_common C++ code. The Julia interface returns exact forms, minimal vectors, stabilizers, facet orbits and labelled neighbours. It needs neither Oscar nor GAP.

Start with Installation, then Usage for a first computation. Backend configuration covers reusing an installation and diagnosing path errors. Development covers source checkouts, build options and tests. The API reference contains the public Julia docstrings.

Scope

The exporter accepts upstream T-space descriptions, including classical forms, real and imaginary quadratic forms, group-invariant spaces and spaces supplied by matrix files. Fields and dimensions are not restricted to the regression examples. Its compiled arithmetic path uses exact GMP integers and rationals; requests for other arithmetic paths are reported explicitly.

The wrapper checks the executable, process and export protocol. Independent mathematical validation belongs in the caller. ArithmeticVoronoi provides exact validation, two-cells, GL/SL/PSL presentations and constructive matrix-to-word algorithms.

First computation

After installation has built the backend:

using PerfectForms
result = enumerate_perfect_forms(5)
length(result.data["representatives"]) # 2
